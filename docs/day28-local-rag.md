# Локальная LLM и RAG

RAG-чат выполняет путь ответа локально: Qwen формирует поисковый вопрос,
multilingual E5 строит embedding, FAISS выбирает кандидатов, локальный
cross-encoder ранжирует источники, а Qwen формирует ответ с проверенными
цитатами. Облачный провайдер включается только явным выбором.

## Подготовка

Для быстрого старта можно скопировать PDF, индекс и локальные snapshot-модели
из соседнего W5:

```bash
pip install -r requirements-indexing.txt
python scripts/prepare_local_rag.py --source ../ai-challange-w5
```

Скрипт проверяет SHA-256 и не обращается к сети. После подготовки приложение
использует только собственную копию в `data/`; каталог `data/` игнорируется Git.
Если W5 недоступен, скачайте PDF и модели вручную по инструкциям в README, затем
постройте индекс через `DocumentIndex().ensure_built()`.

Сохранённый индекс совместим только с той же embedding-моделью. Загрузчики
используют `local_files_only=True`, поэтому неожиданный fallback в сеть
невозможен.

## Офлайн-проверка

Запустите сервер с запретом внешних соединений backend:

```bash
python scripts/run_rag_offline.py --port 8769 --db /tmp/day28-offline.sqlite3
```

В другом терминале выполните:

```bash
python scripts/smoke_local_rag.py --base-url http://127.0.0.1:8769
```

Сценарий проверяет локальный PDF endpoint, источники, цитаты, память, изменение
ограничений, отрицательный вопрос и сохранение состояния. Сетевой отчёт и
результаты прогона сохраняются в `data/` и не коммитятся.

## Сравнение

Набор `evaluation/day28-questions.json` содержит содержательные и отрицательные
вопросы. Контекст готовится один раз, после чего одинаковые фрагменты передаются
локальной Qwen и DeepSeek:

```bash
python scripts/run_day28_evaluation.py --providers ollama
python scripts/measure_rag_cold_start.py
```

По умолчанию отчёты записываются в `data/day28-*.json`. Они предназначены для
конкретного локального запуска и не являются частью продуктового baseline.

## Ограничения

- точное совпадение цитаты подтверждает происхождение текста, но не доказывает
  смысловую поддержку тезиса;
- качество и скорость зависят от локальной модели, её весов и оборудования;
- отрицательный вопрос без подходящих фрагментов должен завершаться отказом без
  вызова генератора;
- индексы и веса не хранятся в Git и должны быть подготовлены отдельно.
