# RAG по документации проекта

Единственный корпус — README.md и Markdown-файлы docs/ текущего checkout.
Локальная E5 строит embeddings, FAISS выбирает кандидатов, cross-encoder
ранжирует источники, а Qwen или явно выбранный DeepSeek формирует ответ.

## Подготовка

```bash
pip install -r requirements-indexing.txt
python scripts/prepare_local_rag.py --source ../ai-challange-w5
```

Скрипт копирует только локальные веса E5 и reranker и строит новый индекс
документации этого проекта. Если веса уже подготовлены, выполните:

```bash
python scripts/build_project_index.py
```

Загрузчики используют local_files_only=True. Индекс в data/project_index/
содержит отдельные стратегии fixed и structure, хеш каждого файла и отпечаток
всего корпуса. Изменение, добавление или удаление документа вызывает перестроение
при следующем запросе. Модели и индекс не хранятся в Git.

## Источники

Фрагменты сохраняют исходный Markdown, путь, заголовок раздела и номера строк.
Цитаты проверяются на точное присутствие в найденном фрагменте. Ссылка открывает
локальный документ с подсветкой строки; если файл изменился после ответа,
сервер сообщает об этом вместо показа другой версии под старой цитатой.

Отсутствие подходящих фрагментов приводит к ответу о недостатке документации.
Совпадение цитаты подтверждает происхождение текста, но смысловую поддержку
тезиса необходимо проверять отдельно.
