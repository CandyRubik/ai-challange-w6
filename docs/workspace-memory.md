# Чаты и общая память

Приложение работает как одно рабочее пространство. Все чаты доступны в общем
списке. Новый чат сразу принимает сообщения и позволяет создать задачу.
Персонализация через профили пользователей и интервью удалена.

Рабочая память и состояние задачи принадлежат конкретному чату. Долговременная
память общая для всех чатов. /goal, /constraint и /decision меняют рабочую память;
/fact, /preference и /knowledge сохраняют данные для следующих чатов.
Очистка истории удаляет чаты и их рабочую память, сохраняя общие знания.
Новая цель создаёт отдельный чат с собственной рабочей памятью; исходный чат
и его задача сохраняются. Ссылка на родителя доступна в шапке новой ветки.

## Совместимость с прежней базой

При открытии старой SQLite-базы история, сообщения, задачи и записи памяти
сохраняются. Чаты бывших пользователей отображаются в одном списке, а их
долговременные записи доступны в общей памяти без удаления или перезаписи.

Прежние настройки пользователей остаются в таблице user_profiles как архив.
Старые связи чатов и памяти со scope записываются в legacy_profile_scopes;
рабочие таблицы больше не содержат profile_id. Архив не передаётся модели.
Миграция выполняется транзакционно и допускает повторный запуск.

HTTP API создания, изменения и удаления пользовательских профилей отсутствует.
В messages, sessions и memory API поле profile_id больше не принимается.
Продуктовые инварианты и выбор модели продолжают действовать для каждого хода.
