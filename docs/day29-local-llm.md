# Конфигурации локальной LLM

RAG по документации проекта поддерживает baseline, compact, optimized и q8.
baseline использует контекст 32768 и ответ до 3000 токенов; compact — контекст
8192 и ответ до 1000 токенов; optimized добавляет инструкцию ассистента
разработчика. q8 использует оптимизированную конфигурацию с весами Q8.

RAG_LLM_PROFILE задаёт начальный профиль. Приватный сервис ограничивает
параметры через PRIVATE_MAX_CONTEXT и PRIVATE_MAX_OUTPUT.

## Сравнение

В отдельном RAG-чате можно выбрать второй профиль и нажать «Сравнить».
Одинаковые найденные фрагменты передаются обеим конфигурациям; результаты
содержат цитаты, время и число попыток генерации.

```bash
python scripts/run_day29_evaluation.py --help
```

evaluation/day29-cases.json содержит вопросы и фиксированные выдержки из
документации проекта. Результаты конкретного запуска сохраняются в data/.
Числа от старых корпусов не характеризуют качество ответов по этому проекту.
