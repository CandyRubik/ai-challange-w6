# Оптимизация локальной Qwen

RAG-чат поддерживает профили `baseline`, `compact`, `optimized` и `q8`.
Профиль сохраняется до начала хода, отображается в результате и используется
при повторе после ошибки или перезапуска.

Профиль `optimized` рассчитан на ответы по локальному документу: temperature 0,
контекст 8192 с расширением для обязательных данных, ответ до 1000 токенов и
prompt, который требует сохранять Java-идентификаторы, объяснять ход выполнения
и связывать тезисы с цитатами.

## Сравнение в интерфейсе

В RAG-чате можно выбрать второй профиль и нажать **Сравнить**. Интерпретация,
поиск, память и источники фиксируются один раз, поэтому обе модели получают
одинаковый контекст. Карточки показывают профиль, настройки, модель, время,
токены/с, цитаты и выделение модели.

Если источники не содержат ответа, обе карточки должны явно показать отказ без
генерации. Смена профиля для следующего сообщения не меняет уже выполняющийся
ход.

## Воспроизводимый прогон

После запуска локального Ollama и подготовки Q4/Q8:

```bash
ollama pull qwen3.5:9b-q4_K_M
ollama pull qwen3.5:9b-q8_0
python scripts/run_day29_evaluation.py --output /tmp/day29-evaluation.json
python scripts/run_day29_evaluation.py \
  --question-ids 2 3 6 11 13 16 \
  --power-guard --output /tmp/day29-timing-control.json
python scripts/check_day29_application.py
```

Набор `evaluation/day29-cases.json` содержит зафиксированные вопросы и фрагменты,
а `evaluation/day29-rubric.json` — ожидаемые факты. Скрипты сохраняют полные
отчёты в указанный путь; если путь не задан, используется игнорируемый каталог
`data/`.

## Интерпретация результатов

Автоматические проверки валидируют статус, JSON и происхождение цитат. Они не
заменяют смысловую оценку полноты ответа. Скорость измеряется отдельно для
прогретого и холодного запуска; RSS процессов и выделение модели на Apple
Silicon нельзя складывать, поскольку они используют общую память.

Замеры, интерактивные отчёты и видео конкретного оборудования являются
артефактами запуска. В W6 они не включаются в репозиторий и не влияют на
продуктовый baseline.
