## Spec

Независимый reviewer воспроизвёл три исходных дефекта:

1. Алиасы `importlib.import_module` и `builtins.__import__` могли давать ложный pass.
2. Сравнение по общему запрещённому префиксу скрывало новый конкретный подмодуль.
3. `from package import name` без доказательства происхождения атрибута мог
   создавать ложное архитектурное замечание.

Все исправлены и покрыты регрессионными сценариями. Повторная проверка нашла
дополнительную регрессию: эквивалентная форма прежнего from-import считалась
новым нарушением. Исправление сохраняет возможное происхождение старого импорта;
при неоднозначности возвращает inconclusive без finding, включая wildcard.
Повторный Git-repro подтвердил это, корректное распознавание уже загруженного
parent и обнаружение нового соседнего подмодуля.

Итог: **4 закрытых находки, 0 открытых**.
