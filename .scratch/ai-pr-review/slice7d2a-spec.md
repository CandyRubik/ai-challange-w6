# 7d2a — owner note presentation hooks

- Inline annotations wrap the original report once and keep its complete current
  presentation. Removing the annotation restores that text without a duplicate review.
- Debt notes are separate from the original assessment; incomplete reruns retain only
  that original assessment, without nesting or carrying stale owner applicability.
- Oversized notes use summary/journal fallback instead of re-truncating the original.
- Optional rendering hooks alone confer no authority or change the CI verdict.
  Authenticated application and dispatch activation follow independently.
